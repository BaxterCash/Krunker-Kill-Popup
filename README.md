# Krunker Kill Popup

A configurable kill confirmation for Krunker in Glorp. Copy `KillPopup.user.js` into `glorp/scripts` and enable userscripts. Keep one active copy and store backups outside the scripts folder.

The popup supports stacked kill notifications, multi-kill labels, and appearance settings. It reads Krunker's native HUD events; actual behavior depends on the game client and has not been verified in live gameplay for this release.

For compatibility with the existing Glorp updater, the userscript update URL points to the identical file in [Krunker-Matchmaker](https://github.com/BaxterCash/Krunker-Matchmaker).
